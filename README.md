## Теоретическое исследование цветовых моделей

### Модель CMYK (Cyan, Magenta, Yellow, Key/Black)

- Субтрактивная модель, используемая в полиграфии
- Значения компонентов от 0 до 1
- Цвет формируется при поглощении света красками
- K (чёрный) добавляется для улучшения качества печати и экономии цветов

### Модель LAB (CIELAB)

- Перцептивно-равномерная модель, разработанная CIE
- L - светлота (0-100)
- a - положение между зелёным и красным (-128 до 127)
- b - положение между синим и жёлтым (-128 до 127)
- Независима от устройства вывода

### Модель RGB (Red, Green, Blue)

- Аддитивная модель, используемая в мониторах и дисплеях
- Значения компонентов от 0 до 255
- Цвет получается сложением световых потоков

## Особенности преобразований между моделями

### Преобразование RGB ↔ CMYK

**RGB → CMYK:**
```python
c = 1 - r / 255
m = 1 - g / 255  
y = 1 - b / 255
k = min(c, m, y)
c = (c - k) / (1 - k)  # Нормировка
m = (m - k) / (1 - k)
y = (y - k) / (1 - k)
```

**CMYK → RGB:**
```python
r = 255 * (1 - c) * (1 - k)
g = 255 * (1 - m) * (1 - k)
b = 255 * (1 - y) * (1 - k)
```

### Преобразование RGB ↔ LAB через XYZ

**RGB → XYZ:**
Используется матричное преобразование с предварительной гамма-коррекцией:
```python
def srgb_to_linear(c):
    c = c / 255.0
    return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4
```

**XYZ → LAB:**
Используются эталонные значения белой точки D65 и кубические корни:
```python
def f_lab(t):
    d = 6 / 29
    return t ** (1 / 3) if t > d ** 3 else t / (3 * d ** 2) + 4 / 29
```

- `rgb_to_cmyk(r, g, b)` - преобразование RGB в CMYK

## Механизм автоматической синхронизации

Для предотвращения рекурсивных вызовов используется флаг `self.updating`:

```python
def update_from_rgb(self):
    if self.updating:
        return
    self.updating = True
    # ... вычисления ...
    self.updating = False
```

### Порядок обновления:

1. **Изменение RGB** → пересчёт LAB и CMYK
2. **Изменение LAB** → пересчёт RGB и CMYK (с проверкой границ RGB)
3. **Изменение CMYK** → пересчёт RGB и LAB

### Обработка некорректных значений

При преобразовании LAB → RGB возможно получение значений вне диапазона 0-255. В этом случае:
- Значения ограничиваются границами 0-255
- Выводится предупреждение "RGB усечён!"

3. **Серые тона** - проверка перцептивной равномерности LAB
